# Fiestas Valladolid 2026

Repositorio independiente para la agenda de Fiestas Valladolid 2026 de Aldea Pucela Eventos.

## Desarrollo

```bash
npm install
npm run build
npm run dev
```

La página local queda disponible en `http://127.0.0.1:8002/fiestas-2026/`.

## Alcance

Este proyecto genera solo:

- `/fiestas-2026/`
- `/fiestas-2026/e/<id>/`
- Assets mínimos de la página de fiestas
- `sitemap.xml` y `robots.txt`

Los enlaces al resto de Aldea Pucela Eventos apuntan a `https://eventos.aldeapucela.org/`.
